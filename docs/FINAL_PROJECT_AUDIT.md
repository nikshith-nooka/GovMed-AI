## 3. Research integrity

- **Raw data:** `results/*.db` MD5 unchanged across this pass.
- **Reports:** regenerated by the analysis code. The only differences are `generated_at` and one headline sentence (FIN-02).
- **Paper:** `paper/main.tex` and `paper/main_ncrtht2026.tex` are identical to the verified `audit/2026-10-10` sources.
- **Displayed values:** every value comes from `/api/research/findings`, `/api/cases`, `/api/runs` or the LaTeX tables. Checked in the browser against the report JSON:
  - paired MedQA accuracy 0.43 / 0.40 / 0.447 / 0.403 / 0.43 / 0.373;
  - V2-CL tokens 4818, governance latency 28.6 s, 3.73 calls, 109 hallucination flags.
- **Labelling:**
  - Unavailable values show "—" or "not run in this experiment", never 0.
  - Simulated review stays labelled "an LLM imitating an attending physician… Not a human".
- **API contracts:** additive only. `?experiment` is optional, and omitting it returns exactly the previous response. A test asserts this.
